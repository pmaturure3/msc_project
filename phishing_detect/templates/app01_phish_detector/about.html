About the model

This tool classifies a URL as phishing or legitimate using only the text of the URL (length, character counts, domain structure, entropy and similar features). It does not visit the site, inspect page content or check reputation lists.

Limitations
  • Only the URL text is analysed, so phishing pages on clean-looking domains can be missed.
  • Results depend on the training data, which may not reflect the newest phishing techniques.
  • Use this tool alongside other security controls, not as the only check.
